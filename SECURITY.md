# Security

The installed skill consists of Markdown instructions and display metadata. It does not install dependencies, request credentials, or connect accounts. Repository maintenance scripts validate and package local files.

Do not include secrets, private customer information, or unredacted account exports in issues or examples. If you find an issue that could expose sensitive data, use [GitHub private vulnerability reporting](https://github.com/takimdigital/storytelling-conversion/security/advisories/new) when available. Otherwise open a minimal issue asking the maintainer for a private reporting channel, without exploit details or sensitive data.

Review third-party skill instructions before use, and keep your assistant's normal permission boundaries in place.
